# i2i-search アーキテクチャ

ご要望の「意味で探す商品検索」（画像でもテキストでも、意味の近い商品を返す）を、我々はこう実装する。その方針と、それぞれがもたらす利点。

- デモ: https://i2i-search.cancer6.workers.dev
- リポジトリ: https://github.com/cancer/i2i-search

## 実装方針の全体像

1. 商品もクエリも、AI で「意味の指紋」（数値の並び）に変換し、検索専用 DB での近傍検索に一本化する
2. AI は自前で持たず、Google の AI（Gemini）を API として借りる — 意味への変換も、商品説明文の生成も
3. 基盤はサーバーレス（Cloudflare）。検索処理・画面配信・検索 DB を単一の構成にまとめる
4. 商品説明文は AI が写真から生成し、検索 DB に置く
5. 価格帯・サイズ・色の絞り込みは、意味検索の結果に重ねる後段フィルタとして実装する

## 各方針の利点

### 1. 検索を 1 系統に一本化する

画像検索とテキスト検索を別々の仕組みとして作らず、「意味の指紋の近傍検索」1 つで両方を実現する。

- **開発・保守の費用が 1 系統分で済む**。2 つの検索エンジンを別々に作り、別々に育てる場合と比べ、実装量も障害の起きる場所も半分になる
- **機能追加が両方に同時に効く**。精度改善やデータ拡充が、画像検索とテキスト検索の双方に一度で反映される
- 実測でも、テキスト「革のかばん」で商品名に「革」を含まない本革バッグが上位に出ることを確認済み

### 2. AI は借りる（Gemini API）

- **初期投資がゼロ**。AI 基盤の構築・学習・チューニングに先行費用をかけず、使った分だけの従量課金で始められる
- **AI の性能向上を自動で取り込める**。モデルの改良はサービス側で行われ、こちらの改修なしに恩恵を受ける
- **実装が薄く、納期が短い**。この AI は鍵 1 つで呼べる方式のため、認証基盤の構築が不要。実装が薄いことは、将来の乗り換えが軽いことも意味する（AI を呼ぶ箇所は 1 モジュールに隔離してあり、他社 AI への切り替え影響が局所化される）

### 3. サーバーレス基盤（Cloudflare）

- **固定費がない**。検索処理・画面配信・検索 DB のすべてが従量制で、使われない時間の費用はほぼゼロ。デモ規模なら無料枠に収まる
- **増強・保守の作業が発生しない**。アクセス増には基盤側が自動で追従し、OS 更新や障害対応といった運用作業を持たない
- **構成が単純で障害点が少ない**。配信・処理・DB が同一事業者のマネージドサービスで完結し、管理対象は実質 1 つ

### 4. 商品説明文は AI 生成で検索 DB に置く

- **説明文を人が書かなくてよい**。各商品の紹介文は写真から自動生成され、執筆・校正の人件費がかからない
- **説明が付くほど検索が賢くなる**。生成した説明文は表示用であると同時に検索の材料にもなり、「商品説明の維持」と「検索精度の維持」が同じ 1 つの自動処理で済む
- **商品の入れ替えに自動で追従する**。商品を差し替えれば説明文も作り直され、古い説明が残らない

### 5. 従来型の絞り込みを後段に重ねる

- **既存の購買動線を壊さない**。「1 万円以下」「S サイズあり」「黒」といった、お客様が慣れている条件指定はそのまま使える
- あいまいな探し方（意味）と、はっきりした条件（構造化データ）の両方に、1 つの検索画面で応えられる

## 費用の構造

- かかるのは **AI API の従量課金**と**クラウド基盤の従量課金**のみ。固定費・ライセンス費はない
- デモ規模（商品 48 点）は双方の無料枠内で稼働している

## リスクと依存

- **外部 AI への依存**: 料金改定・仕様変更・レート制限の影響を受ける。緩和策として、AI を呼ぶ箇所を 1 モジュールに隔離し、モデルや提供元の変更が全体に波及しない構造にしてある（実際に、開発中もモデル変更を定数 1 箇所の修正で完了している）
- **反映の時差**: 商品情報の更新から検索への反映まで数分かかる（デモ用途では支障ない）
- **完全一致の保証はない**: 意味での検索は「近いものを並べる」仕組み。型番検索など厳密な検索が必要なら従来型を併用する

## 規模と育て方

- 数百点程度まではこのままの作りで足りる。数千点を超える段階では、絞り込み処理を DB 側に寄せる改修が最初の一手になる — 作り直しではなく、同じ構成のまま部品を強化する形で育てられる
- 検索結果の質は商品写真と説明文の質に比例する。実運用では商品撮影の統一が投資対効果の高いポイント
